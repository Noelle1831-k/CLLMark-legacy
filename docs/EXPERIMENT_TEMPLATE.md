# 实验记录模板

复制本模板到项目文档目录，每次研究变化独立记录。

| 字段 | 内容 |
| --- | --- |
| 问题与可检验假设 | 哪个机制有缺陷？修复后哪个指标应如何变化？ |
| 代码改动 | 模块/规则、Git 提交、源码摘要 |
| 控制变量 | 数据摘要、协议摘要、环境、seed、水印、并发数 |
| 参考实验 | baseline run_id 与配置 |
| 预期判据 | 目标分组指标、容差、必须保持的功能样本 |
| 验证 | 流程测试、试跑、全量 run_id、validation.json |
| 结果 | 前后指标及分母、门禁、新增/减少的失败 ID |
| 反例分析 | 规则性质反例、错误日志、容量丢失、oracle 缺口 |
| 重复与消融 | 多 seed 次数、配置差异、是否保持可比 |
| 结论 | 支持/否定/待补充；证据能支持的范围 |
| 下一步 | 需要修复或补充的数据/方法 |
| 参考变更 | 是否提升基线及原因；不可比时说明变化来源 |

不能用门禁通过代替科研假设验证；不能用 N/A 或容量筛选后的分数代替全量覆盖。
